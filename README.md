# java-lotto-precourse

## 기능 구현 목록 

#### 구입 금액 입력
- 로또 1장의 금액은 `1,000`원이다.
- 따라서, 구입 금액은 1,000원 단위로 입력받는다.
- 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
- 백 만원을 넘는 로또 구매는 금지한다. 
- `예외처리 #1` 입력된 금액이 로또 금액으로 나누어 떨어지지 않는 경우
- `예외처리 #2` 입력된 금액이 로또 금액 미만일 경우
- `예외처리 #3` 입력된 금액이 1,000,000원을 초과하는 경우

#### 입력한 구입 금액만큼의 로또 발행 
- 1장의 로또를 발행할 때, 중복되지 않은 6개의 숫자를 뽑는다.
- 로또 번호의 숫자 범위는 `1~45`까지이다.
- 예를 들어, 10,000원을 입력했다면 10개의 로또가 발행된다.

#### 발행한 로또 정보 출력
- 발행한 로또 수량 및 번호를 출력한다.
- 각 로또 번호는 오름차순으로 정렬하여 보여준다.

#### 당첨 번호 입력 
- 중복되지 않은 6개의 숫자를 입력받는다.
- 마찬가지로 숫자 범위는 `1~45`이다.
- `예외처리 #1` 범위에 속하지 않는 숫자 이외의 것들이 입력될 경우
- `예외처리 #2` 6개의 숫자가 입력되지 않았을 경우
- `예외처리 #3` 중복된 숫자가 입력되었을 경우
- `예외처리 #4` 구분자가 잘못 사용되는 경우
- `예외처리 #5` 비어있거나 null 값일 경우

#### 보너스 번호 입력 
- 당첨 번호 6개와 중복되지 않는 1개의 숫자를 입력받는다.
- 마찬가지로 숫자 범위는 `1~45`이다.
- `예외처리 #1` 범위에 속하지 않는 숫자 이외의 것들이 입력될 경우
- `예외처리 #2` 당첨 번호와 중복된 숫자가 입력된 경우

#### 발행한 로또 당첨 여부 확인 및 결과 출력 
- 사용자가 구매한 로또 번호와 입력한 당첨 번호를 비교한다.
- 모든 로또들을 비교 후에, 당첨 결과를 화면에 출력한다.
- 당첨은 1등부터 5등까지 있다.
- 당첨 기준은 다음과 같다.
    - 1등: 6개 번호 일치 / `2,000,000,000원`
    - 2등: 5개 번호 + 보너스 번호 일치 / `30,000,000원`
    - 3등: 5개 번호 일치 / `1,500,000원`
    - 4등: 4개 번호 일치 / `50,000원` 
    - 5등: 3개 번호 일치 / `5,000원`

#### 수익률 계산 
- 수익률은 소수점 둘째 자리에서 반올림한다. 
    - `예시 : 62.45% -> 62.5%`
